# FORMATO IEEE - PROYECTO REDES Y COMUNICACIÓN DE DATOS I

Según el documento `FORMATO_REDES DATOS.pdf`, el proyecto debe seguir la siguiente estructura y lineamientos:

## Estructura requerida:

1. **PORTADA**
   - Universidad, Carrera, Curso, Título, Integrantes, Docente, Fecha.
   - Título fórmula: Acción + tecnología + contexto.

2. **ABSTRACT**
   - 150-250 palabras, un solo párrafo, en inglés.
   - Estructura: 1. Problema, 2. Solución, 3. Tecnología, 4. Resultado.

3. **KEYWORDS**
   - Palabras clave técnicas (ej. TCP/IP, VLAN, IPv4, Routing, DHCP).

4. **INTRODUCCIÓN**
   - Explica el contexto general.
   - Estructura: 1. Contexto actual, 2. Problema, 3. Impacto, 4. Solución.

5. **PROBLEMA**
   - Describe claramente la necesidad o dificultad.
   - Responde: ¿qué ocurre?, ¿qué falla?, ¿qué consecuencias genera?, ¿a quién afecta?

6. **OBJETIVOS**
   - General: Verbo + acción + propósito.
   - Específicos: Metas pequeñas para cumplir el general.

7. **MARCO TEÓRICO**
   - Para cada concepto: ¿qué es?, ¿cómo funciona?, ¿para qué sirve?, ¿cómo se aplica?
   - Temas recomendados: OSI, TCP/IP, IPv4, IPv6, VLAN, DNS, DHCP, Routing.

8. **DISEÑO DE RED**
   - Construcción lógica y física, cálculos.
   - Debe incluir: switches, routers, servidores, topología, cableado, segmentación.

*Nota: La numeración del PDF salta del 8 al 13, pero la lógica de las secciones finales es:*

9. **RESULTADOS (Sección 13 en el PDF)**
   - Evidencia del funcionamiento.
   - Incluir: capturas Packet Tracer, tablas, pruebas exitosas, conectividad.

10. **CONCLUSIONES (Sección 14 en el PDF)**
    - Responde: ¿qué se logró?, ¿qué aprendieron?, ¿qué mejorarían?

11. **REFERENCIAS IEEE (Secciones 15, 16, 17 en el PDF)**
    - **CRÍTICO:** Debe usar formato IEEE (ej. `[1]`, `[2]`), **NO usar APA** `(Kurose, 2017)`.
    - Mínimo exigido: 2 libros, 2 fuentes Cisco, 1 RFC o paper IEEE.
    - Citar también imágenes y tablas (ej. `Figura 1. Topología [3]`).

12. **CRONOGRAMA Y RÚBRICA**
    - Avances en semanas 9, 11, 13, 15, 17.
    - Rúbrica: Diseño 15%, Direccionamiento 15%, VLAN 15%, Implementación 20%, Documento IEEE 15%, Exposición 10%, Maqueta 10%.
