# Introducción - Semana 5: Lógica Proposicional

**Fuente:** [Video]. YouTube. https://www.youtube.com/watch?v=qg_TKXAiuGc

---

## Tema principal

La lógica proposicional es el análisis de expresiones que pueden ser verdaderas o falsas. Permite formalizar el lenguaje natural mediante símbolos lógicos y tablas de verdad para determinar la validez de fórmulas complejas.

---

## Conceptos clave

| Concepto | Descripción |
|---|---|
| **Proposición** | Expresión con valor de verdad (verdadero o falso); excluye oraciones interrogativas o imperativas |
| **Negador** | Operador que invierte el valor de verdad de una proposición |
| **Conjuntor (y)** | Conecta dos proposiciones; verdadero solo si ambas son verdaderas |
| **Disyuntor (o)** | Conecta dos proposiciones; falso solo si ambas son falsas |
| **Implicador (si… entonces)** | Falso únicamente cuando el antecedente es verdadero y el consecuente es falso |
| **Coimplicador (si y solo si)** | Verdadero cuando ambas proposiciones tienen el mismo valor de verdad |
| **Tabla de verdad** | Representa todas las combinaciones posibles de valores de verdad de las variables de una fórmula |

---

## Clasificación de fórmulas

| Tipo | Descripción |
|---|---|
| **Tautología** | La fórmula es siempre verdadera para cualquier combinación de valores |
| **Contingencia** | El resultado varía según los valores de las variables |
| **Contradicción** | La fórmula es siempre falsa para cualquier combinación de valores |

---

## Conclusión

El método de tablas de verdad es conceptualmente sencillo y efectivo para analizar fórmulas lógicas, pero su costo computacional crece exponencialmente con el número de variables (10 variables → 1024 filas), lo que limita su eficiencia en problemas de gran complejidad.
