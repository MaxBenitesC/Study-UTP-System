# Contexto del Curso: Taller de Programación Web

Este directorio contiene los materiales y proyectos del curso **Taller de Programación Web**, impartido por la M.Sc. Jesamin Melissa Zevallos Quispe. 

El curso abarca las tecnologías fundamentales del desarrollo web front-end, enfocado en HTML5 y CSS3, y avanzando hacia diseños modernos, interactivos y responsivos.

**Responsable Técnico / Especialista:** Max Anderson Benites Corazón (Senior Technical Implementation Specialist, NCR VOYIX)

## Resumen Temático por Semanas

* **SEMANA 1:** Introducción a HTML y CSS.
* **SEMANA 2:** Estructura fundamental de una página web.
* **SEMANA 3:** Integración de formularios y archivos multimedia.
* **SEMANA 4:** Uso y diseño de tablas en HTML.
* **SEMANA 5:** Avance de Proyecto Final 1 (APF1) - **ChapaTuPromo** e integración de conceptos básicos.
* **SEMANA 6:** Personalización profunda del sitio web utilizando CSS.
* **SEMANA 7:** Animaciones, transiciones y transformaciones en CSS para mejorar la experiencia de usuario (UX).
* **SEMANA 8:** Principios de Flexbox y Grid Layout para el posicionamiento y estructuración avanzada de elementos.
* **SEMANA 9:** Diseño responsivo (Responsive Web Design) mediante Media Queries para adaptabilidad multiplataforma.
* **SEMANA 10:** Avance de Proyecto Final 2 (APF2) - Consolidación y exposición del proyecto **ChapaTuPromo**, aplicando de forma integrada HTML5 y CSS3 puro (diseño responsivo, Flexbox/Grid, transiciones y animaciones).

## Proyectos Destacados en el Workspace
* **ChapaTuPromo:** Plataforma web enfocada en reducir el desperdicio de alimentos, donde tiendas venden productos próximos a vencer. Desarrollo puro con HTML5 y CSS3.
* **MaxFinance:** Proyecto web / dashboard financiero con interfaz moderna (UI/UX avanzado, gráficos interactivos con Chart.js).

## Tecnologías y Conceptos Clave
* **Estructura y Semántica:** HTML5, formularios, tablas, contenido multimedia.
* **Estilos y Posicionamiento:** CSS3, modelo de caja, Flexbox, CSS Grid.
* **Interactividad y UX:** Transiciones, transformaciones (`transform`) y animaciones (`@keyframes`).
* **Adaptabilidad:** Diseño responsivo, Media Queries, unidades relativas (viewport, em, rem).
