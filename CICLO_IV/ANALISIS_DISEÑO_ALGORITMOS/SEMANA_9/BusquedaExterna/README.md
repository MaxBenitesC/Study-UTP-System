# BusquedaExterna - Proyecto demo

Proyecto de ejemplo en Java que implementa distintos algoritmos de búsqueda externa:
- Búsqueda secuencial mediante bloques
- Búsqueda secuencial con índices
- Búsqueda por transformación de claves (hash en cubetas)
- Listas invertidas
- Multilistas

Ejecutar:
1. Abrir en NetBeans como proyecto Java (fuente en /src).
2. Ejecutar Main.java. Los datos de ejemplo están en /datos/clientes.txt.
3. Explora y modifica los algoritmos en /src/algoritmos.
