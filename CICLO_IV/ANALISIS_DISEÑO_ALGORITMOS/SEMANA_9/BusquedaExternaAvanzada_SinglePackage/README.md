BusquedaExternaAvanzada - Versión en un solo paquete (busqueda)

Cómo usar:
1. Abrir en NetBeans como proyecto Java (usar la carpeta 'src' como fuente o crear nuevo proyecto y copiar src/busqueda).
2. Ejecutar la clase 'busqueda.Main'.
3. El programa generará archivos en la carpeta 'datos' al primer arranque.
4. Menú interactivo permite ejecutar distintos algoritmos y una comparación automática.

Archivos generados:
- datos/clientes.txt  (texto legible con 20 registros)
- datos/clientes.dat  (registros fijos para RandomAccessFile)
- datos/indice.bin    (índice binario generado)
- datos/cubetas/      (cubetas para hashing)
- datos/resultados.txt (resultados de pruebas)
