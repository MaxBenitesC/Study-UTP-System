Sass y LESS

El lado del cliente se ejecuta en el navegador y se encarga de la interfaz y la interacción con el usuario. El lado del servidor procesa solicitudes, aplica reglas del negocio y consulta bases de datos (MDN Web Docs, 2025). Las tecnologías de esta investigación pertenecen principalmente al lado del cliente.

1. Sass

Sass es un preprocesador de estilos que se convierte en CSS antes de llegar al navegador. Sirve para organizar hojas de estilo y evitar la repetición de código, especialmente en proyectos medianos o grandes (Sass, s. f.).

Características

  • Variables para colores, tamaños y otros valores.
  • Anidamiento de selectores.
  • Mixins, funciones y módulos reutilizables.
  • Utiliza las sintaxis SCSS y Sass.

2. LESS

LESS también es un preprocesador que amplía CSS y luego genera un archivo CSS normal. Sirve para centralizar valores y reutilizar grupos de estilos. Su sintaxis es muy parecida a CSS, por lo que suele ser sencilla de aprender (Less.js, s. f.).

Características

  • Variables identificadas con @.
  • Selectores anidados y mixins.
  • Funciones, operaciones y reglas condicionales.
  • Se compila a CSS compatible con el navegador.

Diferencia principal: Sass y LESS cumplen casi la misma función, pero utilizan distinta sintaxis y herramientas de compilación.

jQuery y Angular

3. jQuery

jQuery es una biblioteca de JavaScript. Sirve para seleccionar y modificar elementos HTML, controlar eventos, crear efectos y realizar solicitudes Ajax utilizando instrucciones breves (jQuery, s. f.).

Características

  • Manipulación sencilla del DOM.
  • Manejo de eventos como clics y envío de formularios.
  • Efectos, animaciones y solicitudes Ajax.
  • Compatibilidad con sistemas web antiguos.

Actualmente JavaScript moderno realiza muchas de estas tareas sin jQuery. Sin embargo, la biblioteca sigue presente en numerosos proyectos existentes.

4. Angular

Angular es un framework web mantenido por Google. Sirve para crear aplicaciones completas y organizadas, principalmente aplicaciones empresariales o de una sola página. Proporciona varias herramientas oficiales dentro de una misma plataforma (Angular, s. f.).

Características

  • Arquitectura basada en componentes.
  • Uso principal de TypeScript.
  • Inyección de dependencias.
  • Enrutamiento, formularios y cliente HTTP integrados.
  • Soporte para renderizado del lado del servidor.

Angular ofrece una estructura completa, aunque requiere más aprendizaje que una biblioteca pequeña como jQuery.

React y Vue

5. React

React es una biblioteca de JavaScript desarrollada para construir interfaces de usuario. Sirve para dividir una pantalla en componentes reutilizables que se actualizan cuando cambia la información de la aplicación (React, s. f.).

Características

  • Componentes reutilizables.
  • Sintaxis JSX para combinar marcado y JavaScript.
  • Manejo de estado mediante Hooks.
  • Flujo de datos principalmente unidireccional.
  • Amplio ecosistema de herramientas.

React es flexible, pero necesita herramientas adicionales para funciones como el enrutamiento de una aplicación completa.

6. Vue

Vue es un framework progresivo de JavaScript. Sirve tanto para añadir interactividad a una página existente como para construir una aplicación completa. Puede incorporarse gradualmente según las necesidades del proyecto (Vue.js, s. f.).

Características

  • Sistema de reactividad.
  • Plantillas y directivas como v-if y v-for.
  • Componentes de archivo único con extensión .vue.
  • Curva de aprendizaje accesible.
  • Soporte para aplicaciones SPA y renderizado en servidor.

Vue combina una estructura clara con facilidad de adopción, por lo que resulta apropiado para proyectos pequeños y medianos.

Conclusión

Sass y LESS se utilizan para mejorar la escritura de CSS; jQuery simplifica tareas de JavaScript; y Angular, React y Vue permiten construir interfaces mediante componentes. Todas son tecnologías principalmente del lado del cliente. La elección depende del tamaño del proyecto, la experiencia del equipo y el nivel de estructura requerido.
