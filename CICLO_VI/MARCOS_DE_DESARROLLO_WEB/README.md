## 🎯 Enfoque y Metodología de Trabajo
Estudio e implementación arquitectónica de los marcos de trabajo (frameworks) web modernos orientados al desarrollo de Single Page Applications (SPAs), Server-Side Rendering (SSR) y aplicaciones cloud-native extensibles.
El curso combina mejores prácticas comunitarias con estándares de producción industrial en la gestión del estado, enrutamiento, consumo de servicios y modularidad.

## 📌 Tecnologías & Ejes Temáticos
- **Componentización & Declaratividad:** Diseño de UI orientada a componentes modulares e independientes.
- **Ecosistema React / Vue / Angular:** Ciclo de vida de componentes, Virtual DOM e hidratación.
- **Gestión de Estado Centralizada:** Redux, Context API, Pinia, Zustand y reactividad moderna.
- **Enrutamiento Avanzado & Rendimiento:** Code-splitting, Lazy Loading y optimización del Bundle.
- **Tooling & DevEx:** Vite, Webpack, ESLint, TypeScript en entornos masivos de frontend.

- [ ] Comparativas de rendimiento y arquitectura entre frameworks.
